# Excel Sales Analytics Dashboard

An interactive sales dashboard built using Microsoft Excel.

## Features
- Dynamic KPI cards
- Interactive PivotCharts and slicers
- Sales and profit analysis
- Product and regional performance analysis

## Tools Used
- Microsoft Excel
- PivotTables and PivotCharts
- Slicers and Timeline

## Dataset
Practice project using 1,000+ records.

## Project Type
Self-learning / Practice Project
